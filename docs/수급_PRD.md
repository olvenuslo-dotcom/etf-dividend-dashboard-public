# PRD — ETF 수급 분석 기능 v1.1 (상장주식수 기반 재설계)

원본 PRD: 2026-08-07 사용자 제공 (v1.0, 대화 기록).
이 문서는 **7.2 판정 규칙 변경**을 반영한 개정판이다. 원본의 "숫자 기준을 바꾸면
문서를 갱신한다" 규칙에 따라 만들었다.

## 왜 바꿨나 (v1.0 → v1.1)

v1.0 은 **투자자별 순매수(기관·외국인)** 를 핵심 입력으로 설계했다. 확인 결과:

| 출처 | 결과 |
|---|---|
| KRX Open API | 투자자별 거래실적 서비스 **없음** (사용자 스크린샷으로 확정, 2026-08-07) |
| pykrx (data.krx.co.kr) | KRX 약관 위반으로 차단 — 폐기 |
| 세이브로 | 예탁결제원(결제기관)이라 일별 매매 주체 데이터를 만들지 않음 |
| 네이버증권 | robots.txt 전면 차단(`User-agent: * Disallow: /`) + 약관상 자동수집 금지 |

대신 KRX Open API **ETF 일별매매정보**에 `LIST_SHRS`(상장주식수)가 있고
**2010-01-04부터** 제공된다. ETF 자금 유출입의 본질은 설정·환매 = 상장주식수
증감이며, v1.0 도 투자자별 데이터의 한계(LP 헤지 혼입)를 주의문으로 달았었다.
→ **상장주식수를 1차 신호로 승격**하고, 투자자별 순매수는 v2 후보로 미룬다
(경로: 증권사 오픈API 또는 KRX 화면 수동 다운로드 반입).

## 7.2 판정 규칙 (v1.1)

숫자 기준은 초기값이며, 조정 시 이 문서를 갱신한다.

| 플래그 | 조건 (모두 충족) |
|---|---|
| 🔴 이탈 경고 | ① 최근 20일 상장주식수 감소 ② 최근 60일 상장주식수 감소 |
| 🟢 유입 신호 | ① 최근 5거래일 연속 상장주식수 증가 ② 최근 20일 상장주식수 증가 |
| ⚠️ 분배율 함정 | ① 연환산 분배율이 비교 대상 중 상위 30% ② 🔴 이탈 켜짐 |

- 20일·60일을 모두 요구하는 오경보 방지 원리는 v1.0 그대로다.
- ⚠ 는 분배율이 연결된 경우에만 계산한다(미연결 시 "분배율 미연결").
- 비교 대상: 분배ETF목록의 연간분배율이 있는 전체 종목.

## 데이터 (v1.1)

- 출처: KRX Open API `/etp/etf_bydd_trd` (공식, `.env` 의 `KRX_OPENAPI_KEY`)
- 항목: 상장주식수·거래대금·종가·NAV — **하루 호출 한 번에 전 ETF**가 온다
- 캐시: `data/flow_cache/etf_YYYYMMDD.csv` — **일 단위**. 받아 둔 날은 다시
  요청하지 않는다(원본 6.3 규칙 유지). 캐시 기준을 임의로 바꾸지 않는다.
- 기간: 20 / 60 / 120 / 200 / 490거래일. 과거는 2010년까지 백필 가능.
- 갱신은 화면 버튼 또는 `python src/flow/fetch.py 60` — 렌더 중 자동 호출 없음.

## 관심종목 (v1.1 간소화)

`data/reference/관심종목.csv` (종목코드, 종목명). 초기값 069500.
v1.0 의 "랭킹 표 각 행 체크박스"는 3,282행 표를 편집 가능 위젯으로 바꿔야 해서
미뤘다 — v1.1 은 수급 탭 안에서 코드 직접 입력으로 추가·삭제한다. 파일을 직접
편집해도 된다.

## 바뀌지 않은 것

진단과 수리 분리(원본 10절), 아키텍처(fetch/metrics/signals 분리 — 순수 계산은
네트워크를 모른다).
