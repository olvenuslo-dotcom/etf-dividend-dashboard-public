# ETF 분배·포트폴리오 대시보드

분배금(배당) 주는 ETF를 **한국·미국 한 표에서** 비교하고, 내 보유종목을 얹어
세후 기준으로 보는 도구입니다. 종목 이름이 아니라 **데이터 값으로만** 판정합니다.

| | 종목 수 | 어디서 |
|---|---|---|
| 한국 상장 | 1,182개 | 세이브로(분배금) + KRX(시세·총보수·분류) |
| 미국 상장 | 2,100개 | nasdaqtrader(목록) + yfinance(배당·시세) + iShares·SPDR(공식 자료) |

## 다른 PC에서 이어받기 (처음 한 번)

```powershell
git clone <저장소 주소>
cd "ETF dividend"
git config core.hooksPath .githooks              # DRM 커밋 차단 (아래 설명)
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
venv\Scripts\python.exe -m pytest tests -q      # 180개 통과하면 정상
venv\Scripts\streamlit run src\dashboard.py
```

`output/분배ETF목록.xlsx` 와 `data/raw/*.csv` 가 저장소에 들어 있어 **바로 대시보드가 뜹니다.**
데이터를 새로 받고 싶을 때만 아래 수집 단계를 돌리세요.

> 파이썬은 **3.11~3.13**을 쓰세요. 3.14에서는 `pandas==2.2.3` 이 설치되지 않습니다
> (휠이 없어 소스 빌드로 넘어가고, MSVC 빌드 도구가 없으면 실패합니다).

### DRM 주의 — 엑셀 산출물은 그냥 커밋하면 안 됩니다

회사 DRM이 걸린 파일은 원래 형식이 아니라 **암호화된 봉투**가 됩니다
(파일 맨 앞이 `DRMONE`). 그 상태로 커밋하면 다른 PC에서 클론했을 때
`Excel file format cannot be determined` 로 대시보드가 안 뜹니다 — 2026-08-07에 실제로 겪었습니다.

- `git config core.hooksPath .githooks` 를 걸어 두면 **커밋 자체가 막힙니다** (`tools/check_drm.py`)
- 막혔으면 `venv\Scripts\python.exe src\classify.py` 로 xlsx를 다시 만들고 커밋하세요 (10초)
- CSV·ICS·소스는 DRM 대상이 아니라 그냥 커밋해도 됩니다

## 데이터 새로 받기

순서대로 돌리면 되고, 각 단계는 **건너뛰어도 나머지가 돌아갑니다**(해당 칸만 빔).

| 단계 | 명령 | 결과 | 걸리는 시간 |
|---|---|---|---|
| 국내 분배금 | `venv\Scripts\python.exe src\collect.py` | `data/raw/seibro_분배금_*.csv` (**2년치**) | 3~5분 |
| **국내 시세·수익률** | `venv\Scripts\python.exe src\etf_refresh.py` | `krx_etf정보_*.csv` + `krx_etf수익률_*.csv` | 몇 초 |
| **미국 ETF** | `venv\Scripts\python.exe src\us_etf.py` | `us_etf_*.csv` + `us_배당_*.csv` | 5~6분 |
| **미국 발행사 자료** | `venv\Scripts\python.exe src\us_issuers.py` | `us_발행사_*.csv` | 10초 |
| 목록 만들기 | `venv\Scripts\python.exe src\classify.py` | `output/분배ETF목록.xlsx` | 10초 |
| 캘린더 만들기 | `venv\Scripts\python.exe src\calendar_ics.py` | `output/분배캘린더.ics` | 2~3분 |

### 매일 자동으로 갱신하기 (윈도우 작업 스케줄러)

한 번만 등록해 두면 **평일 18:30** 에 국내 시세→목록→캘린더가 알아서 갱신됩니다.

```powershell
tools\register_etf_task.bat        # 등록 (권한 오류가 나면 관리자 프롬프트에서)
schtasks /Run /TN "ETF-refresh-daily"      # 지금 한 번 돌려 보기
schtasks /Query /TN "ETF-refresh-daily"    # 등록 상태 확인
schtasks /Delete /TN "ETF-refresh-daily" /F   # 해제
```

`etf_refresh.py → classify.py → calendar_ics.py` 를 차례로 돌리고, **한 단계라도 실패하면
거기서 멈춥니다**(낡은 xlsx 가 새 것인 척하지 않게). 기록은 `data/etf_refresh.log`.
`.env` 의 `KRX_OPENAPI_KEY` 가 있어야 합니다.

> DDR5 현물가도 같은 방식입니다: `tools\register_ddr5_task.bat` (평일 18:00).
> 미국 ETF·세이브로는 자동에 넣지 않았습니다 — 5~6분씩 걸리고 매일 바뀌는 값도 아닙니다.

### 미국 총보수·순자산이 비어 있을 때

야후는 총보수·순자산을 주는 API(`quoteSummary`)에 **호출 제한이 셉니다.** 순서대로 쓰세요.

```powershell
venv\Scripts\python.exe src\us_etf.py issuers   # ① 발행사 공식 자료로 채우기 (제한 없음)
venv\Scripts\python.exe src\us_etf.py loop      # ② 야후를 20분 간격 8판 재시도
venv\Scripts\python.exe src\us_etf.py fill 800  # ③ 한 판만 수동으로
```

배당·시세는 이 제한과 **무관**합니다(다른 경로). 막히는 건 총보수·순자산·운용사·카테고리뿐입니다.

### 사이드바 필터

위에서부터 **화이트리스트 → 내 보유종목 → 계좌 → 상장시장 → 투자지역 → 분배주기 → …** 순입니다.

| 필터 | 하는 일 |
|---|---|
| 화이트리스트 | 회사 계좌로 살 수 있는 종목만/제외 (`data/reference/whitelist.csv`) |
| 내 보유종목 | 지금 들고 있는 것만/제외 (`data/portfolio/보유종목.csv`) |
| 어느 계좌로 살 건가요? | **연금저축·IRP/DC·ISA 를 고르면 미국 종목이 빠집니다** — 그 계좌로는 못 사서 |
| 상장시장 | 한국 / 미국 |
| 투자지역 | 처음에는 **한국·미국만** 켜져 있습니다. 다 지우면 전체 |
| 분배주기 | 주·월·분기·반기·연 / **미분배**(분배 이력이 없는 상장 ETF, 기본 꺼짐) |

화이트리스트·보유종목은 **서로 독립**이라 조합이 됩니다 —
`화이트리스트만` + `보유종목 제외` = 아직 안 산 매매가능 종목.

### 탭 5개

| 탭 | 내용 |
|---|---|
| 📋 종목 목록 | 종목명 옆에 **코드**(국내 6자리 / 미국 티커)가 항상 붙습니다. 연분배율·총수익·총보수·주기 등 |
| 📅 다가오는 일정 | **목록 / 🗓 달력 / 📊 월별 건수** 세 가지로 봅니다 |
| 📉 NAV 침식 | 종목 하나를 골라 NAV·종가 추이 (미국 종목은 KRX 조회 대상이 아니라 빠집니다) |
| 📊 NAV 비교표 | 기준을 골라 N개 일괄 조회. 아무 칸이나 클릭하면 아래에 상세 |
| 💼 내 포트폴리오 | 평가손익·받은 분배금·현금흐름·리밸런싱·실현손익 |

표가 옆으로 밀리면 표 위의 **표시할 항목 고르기**에서 칸을 끄세요(기본 9칸, 스크롤 없음).

### ⚠ 고배당의 함정 — 꼭 보세요

**`분배율`(직전 1회분)만 보면 안 됩니다.** 주기가 다르면 비교가 안 되고,
분배한 만큼 가격이 빠지기 때문입니다. 표에 있는 두 칸을 나란히 보세요.

| 칸 | 뜻 |
|---|---|
| **연분배율** | 최근 12개월 분배금 합 ÷ 현재가 — **주기가 달라도 이것끼리는 비교됩니다** |
| **총수익(1년)** | 1년 가격 변화율 + 연분배율 — **실제로 번 돈**에 가까운 값 |

연분배율이 20%를 넘는데 총수익이 마이너스면 **원금을 헐어 나눠주는 중**입니다.
그런 종목이 있으면 표 위에 노란 경고가 뜹니다. 미국 상장 ETF 중
`T-REX 2X Long SMR`(연 980% 분배, YTD -98%) 같은 레버리지·인버스·YieldMax 계열이 여기 걸립니다.
전략 칸에서 **레버리지·인버스·커버드콜**로 갈라 놓았으니 같이 보세요.

## 💼 내 포트폴리오 쓰는 법

1. 증권사 앱 **잔고 화면을 캡처**해 클로드 코드 대화창에 올리면 `data/portfolio/보유종목.csv` 로 만들어 줍니다.
   이때 **어떤 계좌인지 알려주세요** — 일반(위탁)·연금저축·퇴직연금(IRP/DC)·ISA
   (증권사 앱에 **엑셀 내보내기**가 있으면 그게 더 정확합니다)
2. 또는 대시보드 표에서 직접 고치고 **저장**

CSV 형식: `계좌,계좌유형,종목명,KRX코드,수량,매수단가,매수일,메모`
- `KRX코드`는 국내 6자리 또는 **미국 티커**(SCHD). 비우면 종목명으로 찾습니다
- **`매수일`을 넣으면 그 이후 받은 분배금만** 셉니다. 비우면 최근 12개월 전체(실제보다 클 수 있음)
- `계좌유형`을 비우면 **일반(위탁)** 으로 봅니다(세금을 적게 잡지 않으려고)

### 계좌유형별 분배금 과세

| 계좌유형 | 받을 때 | 최종 |
|---|---|---|
| 일반(위탁) | 15.4% 원천징수 | 15.4% (금융소득 2천만원↑ 종합과세) |
| 연금저축 | **0%** (과세이연) | 연금 수령 시 3.3~5.5% / 연금 외 인출 16.5% |
| 퇴직연금(IRP/DC) | **0%** (과세이연) | 연금 수령 시 3.3~5.5% / 중도해지 16.5% |
| ISA | **0%** | 순이익 200만원(서민형 400만원)까지 비과세, 초과분 9.9% |
| **미국 상장분** | **15% (현지 원천징수)** | 국내 추가 과세 없음, 단 금융소득종합과세 대상 |

> ⚠ 나이·인출방식·금융소득종합과세 여부로 달라집니다. **참고용**입니다.
> **연금·IRP/DC·ISA 계좌로는 미국 직접 상장 ETF를 살 수 없습니다** — 넣으면 대시보드가 경고합니다.
> 미국 종목의 **매매차익은 양도소득세 22%**(연 250만원 공제)라 이 계산에 들어 있지 않습니다.

## 판정 규칙

- **청산분배 제외** — 상장폐지 때 주는 건 정기 분배가 아닙니다.
- **분배주기** — 최근 12개월 **지급 횟수**로 판정

  | 지급 횟수 | 주기 |
  |---|---|
  | 40회 이상 | 위클리 |
  | 7~39회 | 월 |
  | 3~6회 | 분기 |
  | 2회 | 반기 |
  | 1회 | 연 |
  | 0회 | 미분배 |

  지급 **간격**(중앙값)으로도 따로 판정해서 결과가 다르면 비고에 `주기 확인`을 답니다.
  국내엔 위클리가 없고, 68개는 전부 미국 상장분입니다.

  > 세이브로는 **2년치**를 받지만 주기 판정은 **최근 12개월만** 씁니다. 자르지 않으면
  > 분기배당이 2년 8회로 세어져 '월'(7~39회)로 뒤집힙니다. 앞 12개월은
  > **분배금성장률**(분배금이 늘었나)을 내는 데만 씁니다.
- **국내/해외** — 종목명이 아니라 유형 데이터값(`해외지수/해외지수`)으로 봅니다.
- **상장시장** — 어느 거래소에 상장됐나(한국/미국). '국내해외'(무엇에 투자하나)와 **다릅니다**.
- **매수마감일** — 국내는 지급기준일 **2영업일 전**(배당락 1영업일 전),
  미국은 야후가 주는 날짜가 이미 배당락일이라 **1영업일 전**. 공휴일도 각 나라 것으로 계산합니다.
- **투자지역·테마섹터·전략은 추정값** — KRX/야후에 세부 필드가 없어 **기초지수명·카테고리** 문구에서
  규칙으로 뽑았습니다. 못 뽑은 건 '기타'. 자산분류·과세유형은 받은 값 그대로입니다.
- **금액 단위** — 미국 종목의 시총·분배금·종가는 **수집 당시 환율로 원화 환산**한 값입니다
  (환율은 `us_etf_*.csv` 의 `환율` 칸). 비율(%)은 통화와 무관합니다.
